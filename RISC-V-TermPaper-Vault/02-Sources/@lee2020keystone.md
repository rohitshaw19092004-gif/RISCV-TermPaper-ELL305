> Physical memory protection (PMP), enclave frameworks such as Sanctum [[@costan2016sanctum]], MI6 [[@bourgeat2019mi6]] and Keystone [[@lee2020keystone]], control-flow integrity via landing pads and shadow stacks [[@riscv-cfi]], and proposals for temporal partitioning are live design questions.

> Sanctum [[@costan2016sanctum]] showed that strong software isolation, including protection against page-table and cache side channels, is achievable with minimal hardware extensions to a RISC-V core; MI6 [[@bourgeat2019mi6]] extended enclave protection to a speculative out-of-order core, which is the hard case; and Keystone [[@lee2020keystone]] provides an open, configurable TEE framework built on those foundations.
